# 윈도우 판 — BrainCo Revo2 Hand Camera Tracking

**이 폴더 하나로 완결됩니다.** 내려받아 원하는 자리에 두고 `.bat` 을 두 번 누르면 됩니다.

> 전체 설명(원리·검증·한계)은 저장소 최상위 [README.md](../README.md) 를 보십시오.
> 이 폴더는 같은 프로그램을 **윈도우에서 두 번 눌러 쓸 수 있게** 만든 판입니다.

## 쓰는 법

| 누를 것 | 무엇을 합니다 |
|---|---|
| **`로봇손_따라하기.bat`** | 웹캠 → 로봇손. 처음이면 파이썬·꾸러미·모델을 알아서 갖춥니다 |
| `웹캠만_보기.bat` | 로봇 없이 화면만 봅니다 |
| `작은창으로_따라하기.bat` | 작은 창으로 |
| `연결진단.bat` | 로봇손이 안 잡힐 때 **무엇이 문제인지** 가려 줍니다 |
| `환경조사.bat` | 이 PC 의 파이썬·카메라·COM 포트를 조사합니다 |

자세한 단계는 [사용법.md](./사용법.md) 에 있습니다.

## 갖춰지는 것 · 갖춰지지 않는 것

**알아서 갖춰집니다** — 파이썬(계정 안에만), 꾸러미, 손 랜드마크 모델, 제조사 SDK(동봉).

**드라이버는 끝까지 대신 깔아 드리지 않습니다.**
먼저 **윈도우 업데이트 → 제조사 공식 설치 파일** 순서로 **자동 설치를 시도**하고,
안 되면 **받는 곳을 열어 주고 손으로 설치하는 방법을 단계별로 안내**합니다.
관리자 권한 창(UAC)은 **사람이 승인**합니다 — 대신 눌러 주지 않습니다.

| 직접 받는 곳 | 무엇 |
|---|---|
| <https://ftdichip.com/drivers/vcp-drivers/> | 통신 칩 드라이버(FTDI VCP) — 없으면 COM 포트가 안 생깁니다 |
| <https://www.brainco-hz.com/docs/revolimb-hand/en/revo2/download.html> | BrainCo 공식 자료실 — 드라이버·SDK·설명서 |

## 확인된 환경

Windows 10 · Windows 11 (데스크톱 PC · 노트북에서 정상 구동 확인)

## 장비 없이 확인하기

```bat
python tests_드라이버.py        :: 드라이버 도우미 분기 시험
python tests_맞춤설치.py        :: 설치 흐름 시험
python src\hand_tracking_control.py --self-test   :: 계산 논리 검증
```
